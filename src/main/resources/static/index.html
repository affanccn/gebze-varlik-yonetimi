Proje Durumu: Başlangıç İskeleti

Bu ekran, Gebze Belediyesi Varlık Yönetimi uygulamasının ilk teknik iskeletidir. Gerçek belediye verisi veya uydurma gösterge sayıları içermez. Arka uç, Java 25 LTS, Spring Boot 4.1.2 ve en güncel Oracle Database 23ai (ojdbc17, Hibernate 7.4, Flyway 12.4) altyapısıyla yapılandırılmıştır.

Planlanan Modül Yapısı

common

Ortak altyapı bileşenleri, sistem sağlık kontrolü (/api/health) ve paylaşılan yardımcılar.

asset

Varlık ve envanter tanımlama modülü (iş kuralları netleştiğinde eklenecektir).

movement

Varlık giriş, çıkış ve yer değişikliği hareketleri modülü (iş kuralları netleştiğinde eklenecektir).

assignment

Zimmet ve sorumluluk atama modülü (iş kuralları netleştiğinde eklenecektir).

Teknik Altyapı Özeti

  • Arka Uç (Backend): Java 25 LTS & Spring Boot 4.1.2
  • Ön Yüz (Frontend): Yalın HTML5, CSS3 ve Tarayıcı JavaScript (Framework bağımsız)
  • Veritabanı Altyapısı: Oracle Database 23ai LTS (ojdbc17 23.26.3.0.0, Spring Data JPA / Hibernate 7.4, Flyway 12.4)
  • Sağlık Kontrolü Uç Noktası: GET /api/health
